Monatsfeld

Mit dem Eingabetyp "month" kann der Benutzer einen Monat und ein Jahr auswählen.

Hinweis: Der Eingabetyp "type=month" wird von Firefox, Safari und Internet Explorer 11 nicht unterstützt.

Zahlenfeld

Das input type="number" definiert ein Eingabefeld für Zahlen.

Mit den Attributen min und max kannst du Zahlenbegrenzungen für das Eingabefeld festlegen:

Schieberegler

Je nach Browserunterstützung wird der Eingabetyp "range" als Schieberegler angezeigt.

Suchfeld

Der Eingabetyp input type="search" wird für Suchfelder verwendet (es verhält sich ähnlich wie ein normales Texteingabefeld).

Der Eingabetyp input type="tel" wird für Eingabefelder verwendet, in die eine Telefonnummer eingegeben werden soll:





Format: 123-45-678

Ein Zeitauswahlfeld anzeigen

Der Eingabetyp input type="time" ermöglicht es dem Benutzer, eine Uhrzeit auszuwählen (ohne Zeitzone).

Wenn der Browser diese Funktion unterstützt, wird beim Anklicken des Eingabefeldes eine Zeitauswahl angezeigt.

Hinweis: Der Eingabetyp "type=time" wird im Internet Explorer 11 nicht unterstützt.

Ein URL-Eingabefeld anzeigen

Der Eingabetyp input type="url" wird für Eingabefelder verwendet, in die eine URL-Adresse eingegeben werden soll:

Ein Wochenauswahlfeld anzeigen

Der Eingabetyp input type="week" ermöglicht es dem Benutzer, eine Kalenderwoche und ein Jahr auszuwählen.

Wenn der Browser diese Funktion unterstützt, wird beim Anklicken des Eingabefeldes eine Kalenderauswahl angezeigt.

Hinweis: Der Eingabetyp "type=week" wird nicht von allen Browsern unterstützt.
